Welcome! These are the instructions to setup and run the Wavelet detection and Likelihood Evaluation of X-ray sources (WavLEX) tool developed by Van Der Ark et al. If you want to know more about WavLEX please see the publication "The Chandra Legacy Survey of the Central 6 x 4 degrees around Sgr A*. I. WavLEX Source Detection Tool" in arXiv (DOI pending) and ApJS (DOI pending).

The self-contained WavLEX python source code WavLEX_v1.py is available in this repository. WavLEX was developed using CIAO 4.17 and CalDB 4.12.4; however, the commands used are backward compatible with CIAO 4.14. Python 3.7 and MARX 5.5.3 or later are also required, although these are included when downloading CIAO. Make sure that WavLEX is run in an environment in which these packages are enabled. Refer to https://cxc.cfa.harvard.edu/ciao/download/ for further guidance.
 
The only specialized WavLEX add-on is \texttt{nh2\_lookup.py}, which requires the \texttt{ftools} package, as well as the CO intensity map from \citet{2001ApJ...547..792D}, which must be available in the local environment. As discussed in \S\ref{subsec:additions}, the $N_{\mathrm{HI}}$ and $N_{\mathrm{H_2}}$ estimates were a specific requirement of the CLS catalog and were tailored to that region. It is up to individual WavLEX users to decide whether they want $N_{\mathrm{HI}}$ and $N_{\mathrm{H_2}}$ estimates based on public survey data and, if so, to adjust \texttt{nh2\_lookup.py} accordingly.
 
To run WavLEX \unskip, users must enter their ObsID(s) on line XXX of \texttt{WavLEX.py}, enter the minimum and maximum energy in keV on line YYY to set the energy band, and set the desired output directory path on line ZZZ. A source list for each ObsID will appear in the output directory as \texttt{\{ObsID\}\_likelihood\_results.csv}. In its current version, WavLEX is not compatible with merged or co-added observations, so users with overlapping observations must decide for themselves how to crossmatch sources between source lists.
