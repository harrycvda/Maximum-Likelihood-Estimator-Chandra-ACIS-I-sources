Welcome! These are the instructions to setup and run the Wavelet detection and Likelihood Evaluation of X-ray sources (WavLEX) tool developed by Van Der Ark et al. If you want to know more about WavLEX please see the publication "The Chandra Legacy Survey of the Central 6 x 4 degrees around Sgr A*. I. WavLEX Source Detection Tool" in arXiv (DOI pending) and ApJS (DOI pending).

The self-contained WavLEX python source code WavLEX_v1.py is available in this repository. WavLEX was developed to detect Chandra X-ray Observatory sources using CIAO 4.17 and CalDB 4.12.4; however, the commands used are backward compatible with CIAO 4.14. Python 3.7 and MARX 5.5.3 or later are also required, although these are included when downloading CIAO. Make sure that WavLEX is run in an environment in which these packages are enabled. Refer to https://cxc.cfa.harvard.edu/ciao/download/ for further guidance.
 
The only specialized WavLEX add-on is nH_lookup.py, which requires the HEASARC ftools package (https://heasarc.gsfc.nasa.gov/docs/software/ftools/), as well as the CO intensity map wco_map.fits produced by (Dame et al., 2001, ApJ, 547, 792, https://doi.org/10.1086/318388), which must be available in the local environment. Looking up nH through WavLEX was a specific requirement of cataloging the Galactic Center fields WavLEX was developed on. It is up to individual WavLEX users to decide whether they want nH1 and nH2 estimates based on public survey data for their own observations, and to adjust nH_lookup.py accordingly.
 
To run WavLEX, users must enter their ObsID(s) on line XXX of WavLEX_v1.py, enter the minimum and maximum energy in keV on line YYY to set the energy band, and set the desired output directory path on line ZZZ. A source list for each ObsID will appear in the output directory as {ObsID}_likelihood_results.csv. In version 1, WavLEX is not compatible with merged or co-added observations, so users with overlapping observations must decide for themselves how to crossmatch sources between source lists.
